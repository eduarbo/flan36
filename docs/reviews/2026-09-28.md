# General review · September 28, 2026

Follow-up: [implementation plan and verification](reliability-plan.md). This audit preserves the original observations.

**Seven confirmed issues. The first two can lose saved customization.** Review of `692ec64a75889ec9ee8cd2e1016bfe1f3e9dd917`; fixes are not included in this report.

Two independent static reviews were followed by isolated Chromium reproductions. The audit covers viewer state, import/export, compatibility, controls and consistency of CAD evidence. It does not claim a new physical or electrical qualification.

| Priority | Finding | Observed effect | Smallest correction |
|---|---|---|---|
| P1 · GR01 | Rejected saved data is overwritten during startup | A complete saved configuration tagged revision H, with a custom color, becomes revision I defaults simply by opening the viewer. The warning appears after the original value has been replaced. | Preserve rejected data for recovery; separate initial display from saving. |
| P1 · GR02 | Tabs overwrite one another | Change K01 to `#123456` in tab A, then choose Retro TV in an already-open tab B. The saved key color returns to `#e9dfc6` without a conflict warning. | Detect stale saved state before writing; offer reload or explicit conflict resolution. |
| P2 · GR03 | Invalid import partially changes the scene | `frames.right.style="constructor"` passes JavaScript validation. Import fails while resolving geometry, but the left base has already changed. Its exported GLB material is red while the embedded configuration still says `#253639`. Python rejects the same style. | Validate own catalog keys and types, resolve all assets first, then apply atomically. |
| P2 · GR04 | Legacy import changes case geometry | A valid revision I file without `cases` imports as Level in both JavaScript and Python. The documented compatibility contract promises Solid with covers. This also changes selected print files. | Use a fixed legacy migration rule, independent of today's default preset. |
| P2 · GR05 | Battery choice affects the hidden half | With View set to Left and the inspector showing “left half”, choosing 301230 changes **both** batteries. The JSON supports separate choices but this control does not. | Add an explicit Both / Left / Right target and honor it. |
| P2 · GR06 | “Current” delivery evidence points to an older viewer | The Level guide links a receipt whose viewer and builder hashes differ from the reviewed version. | Mark that receipt as historical and link the successor evidence by scope. |
| P3 · GR07 | Inspector descriptions lag behind the model | It still describes a battery saddle, the former 7 / 8.8 mm connector discrepancy and three case designs. Current documentation describes the floor-mounted cell, 6.09 mm candidate and four cases. | Update the component descriptions from the current design data. |

P1 means address first because customization can be lost. P2 means a reproducible correctness or workflow defect. P3 means misleading presentation. GR03 is a local malformed-input defect; no remote compromise was demonstrated.

## Reproduction and evidence

- **GR01–02:** [startup/persistence](../../viewer/app.js#L253), [restore](../../viewer/storage.js#L9). The browser probe uses a disposable profile and two ordinary tabs. It never touches an existing user configuration.
- **GR03:** [catalog validation](../../viewer/config.js#L26), [sequential application](../../viewer/app.js#L235). The probe reads the actual exported GLB material and embedded configuration, not just the error message. No uncaught JavaScript error is required to produce this mismatch.
- **GR04:** [JavaScript normalization](../../viewer/config.js#L16), [Python normalization](../../tools/keycap_config.py#L38), [published compatibility contract](../customize.md#case-geometry).
- **GR05:** [battery click handler](../../viewer/app.js#L317). The probe records both the selected half and the two resulting profiles.
- **GR06:** [Level guide](../level-stack.md), [older receipt](../../validation/revI-level-delivery.json), [successor cap-direction receipt](../../validation/revI-cap-rows.json). The native FCStd still matches the Level geometry receipt, SHA-256 `1c9d3db85b360fea61ed891d6262d0b49055a3fde4ac0912038c96a59ded84cd`. The stale link does **not** establish a new CAD defect or invalidate the later cap tests.
- **GR07:** [component descriptions](../../viewer/explorer.js#L7), [case subtitle](../../viewer/template.html#L43).

[Recorded browser observations](../../validation/general-review-20260928.json) include the reviewed viewer hash. All 33 enumerated review inputs stayed unchanged during the independent reviews.

## Improvements and discoveries

**Loading and memory deserve a separate optimization pass.** The self-contained HTML is **63.94 MiB**. Its embedded scene expands to **124.21 MiB of JSON**, including **21.62 MiB of printable assets** loaded even when someone only wants to inspect the model. The isolated desktop run reached readiness in **3.89 seconds** with **424.18 MiB of used JavaScript heap** at that instant. This is one local measurement, not a phone benchmark, peak-memory measurement or network transfer size. Preserve the offline artifact while evaluating a lighter online loading path and measure both before choosing an implementation.

**Undo would protect experimentation.** Theme and preset changes immediately replace and save selections. A short undo history or explicit saved designs would make trying colors and frames less costly. This is a feature opportunity, separate from the data-loss bugs above.

**The test gap is state transitions.** Zero runtime errors and successful happy-path exports did not detect rejected-import inconsistency, startup data loss or concurrent-tab overwrites. Add those negative cases, with scene/configuration/storage comparisons, when implementing fixes.

## Run the bounded browser probe

From the repository root, with the locked viewer dependencies installed and a local Playwright/Chromium runtime:

```sh
FLAN36_PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
FLAN36_BROWSER=/absolute/path/to/chromium \
node tools/review_general.cjs
```

The probe writes `build/general-review/result.json`, a disposable module bundle and `rejected-import.glb`. These are ignored, reproducible artifacts. Exit zero means the probe completed; inspect its observations to determine whether the reported defects still reproduce. It does not repair or publish the viewer. The committed observation receipt preserves this reviewed snapshot even after future corrections.
